# Personal Resume Workspace

该目录保存私人简历数据。

```text
Markdown/master/    完整简历，职业事实的唯一权威来源
Markdown/tailored/  面向具体 Job 的定制版本
Markdown/shared/    中英文共享页眉
PDF/                从 Markdown 生成的审阅或投递版本
```

通用规则、样式和导出器位于 `../../resume/`。目标职位与 Job Brief 位于相邻的 `../jobs/`。修改简历正文前必须遵循 `../../resume/RESUME_RULES.md` 的确认流程。
