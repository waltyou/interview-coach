# Resume Capability

该目录是 Interview Coach 的通用简历能力，保存维护协议、固定样式、图标与 PDF 导出器。个人数据保存在相邻的 `workspace/resume/`，目标职位保存在 `workspace/jobs/`。

```text
resume/                     通用规则、样式和导出工具
workspace/resume/Markdown/  私人完整简历、定制版本与共享页眉
workspace/resume/PDF/       私人导出结果
workspace/jobs/             Job、Job Brief 与职位原始资料
```

开始简历任务前读取 `AGENTS.md` 和 `RESUME_RULES.md`。导出说明见 `PDF_EXPORT.md`。
